৮ম শ্রেণি: গণিত

পঞ্চম অধ্যায়: বীজগণিতীয় ভগ্নাংশ — সৃজনশীল প্রশ্ন ও উত্তরমালা

উদ্দীপক: তিনটি বীজগণিতীয় ভগ্নাংশ হলো: A = x − 2x2 + 2x − 3, B = x + 3x2 + 5x + 6 এবং C = 1x2 + x − 2
  • (ক) A ভগ্নাংশের হরকে উৎপাদকে বিশ্লেষণ করো। [২]
  • (খ) A ও B কে সাধারণ হরবিশিষ্ট (সমহরবিশিষ্ট) ভগ্নাংশে প্রকাশ করো। [৪]
  • (গ) A + B − C এর সরল মান নির্ণয় করো। [৪]

সমাধান ১:

(ক) এর সমাধান:
A ভগ্নাংশের হর = x2 + 2x − 3
= x2 + 3x − x − 3
= x(x + 3) − 1(x + 3)
= (x + 3)(x − 1)
উত্তর: (x + 3)(x − 1)
(খ) এর সমাধান:
A এর হর = x2 + 2x − 3 = (x + 3)(x − 1) [ 'ক' হতে প্রাপ্ত ]
B এর হর = x2 + 5x + 6 = x2 + 3x + 2x + 6 = x(x + 3) + 2(x + 3) = (x + 3)(x + 2)

অতএব, হরদ্বয়ের ল.সা.গু = (x + 3)(x − 1)(x + 2)

ল.সা.গু ÷ A এর হর = (x + 2)
সুতরাং, A = (x − 2)(x + 2)(x + 3)(x − 1)(x + 2) = x2 − 4(x + 3)(x − 1)(x + 2)

ল.সা.গু ÷ B এর হর = (x − 1)
সুতরাং, B = (x + 3)(x − 1)(x + 3)(x + 2)(x − 1) = x2 + 2x − 3(x + 3)(x − 1)(x + 2)

উত্তর: নির্ণেয় সমহরবিশিষ্ট ভগ্নাংশদ্বয় হলো:
x2 − 4(x + 3)(x − 1)(x + 2) এবং x2 + 2x − 3(x + 3)(x − 1)(x + 2)
(গ) এর সমাধান:
C এর হর = x2 + x − 2 = x2 + 2x − x − 2 = x(x + 2) − 1(x + 2) = (x + 2)(x − 1)
হরগুলোর ল.সা.গু = (x + 3)(x − 1)(x + 2)

প্রদত্ত রাশি = A + B − C
= x − 2(x + 3)(x − 1) + x + 3(x + 3)(x + 2) − 1(x + 2)(x − 1)
= x − 2(x + 3)(x − 1) + 1x + 2 − 1(x + 2)(x − 1)
= (x − 2)(x + 2) + (x + 3)(x − 1) − (x + 3)(x + 3)(x − 1)(x + 2)
= (x2 − 4) + (x2 + 2x − 3) − x − 3(x + 3)(x − 1)(x + 2)
= 2x2 + x − 10(x + 3)(x − 1)(x + 2)
= 2x2 − 4x + 5x − 10(x + 3)(x − 1)(x + 2)
= 2x(x − 2) + 5(x − 2)(x + 3)(x − 1)(x + 2)
= (x − 2)(2x + 5)(x + 3)(x − 1)(x + 2)
উত্তর: (x − 2)(2x + 5)(x + 3)(x − 1)(x + 2)
উদ্দীপক: x2 − 3x + 1 = 0 একটি বীজগণিতীয় সমীকরণ এবং P = a3 − b3a + b, Q = a2 − ab + b2a2 − b2
  • (ক) x + 1x এর মান নির্ণয় করো। [২]
  • (খ) প্রমাণ করো যে, x4 + 1x4 = 47 [৪]
  • (গ) P × Q ÷ a3 + b3a − b কে লঘিষ্ঠ আকারে প্রকাশ করো। [৪]

সমাধান ২:

(ক) এর সমাধান:
দেওয়া আছে, x2 − 3x + 1 = 0
বা, x2 + 1 = 3x
উভয়পক্ষকে x দ্বারা ভাগ করে পাই,
x2x + 1x = 3xx
বা, x + 1x = 3
উত্তর: 3
(খ) এর সমাধান:
'ক' হতে পাই, x + 1x = 3
উভয়পক্ষকে বর্গ করে পাই,
(x + 1x)2 = 32
বা, x2 + 2 × x × 1x + 1x2 = 9
বা, x2 + 2 + 1x2 = 9
বা, x2 + 1x2 = 9 − 2 = 7

পুনরায় উভয়পক্ষকে বর্গ করে পাই,
(x2 + 1x2)2 = 72
বা, (x2)2 + 2 × x2 × 1x2 + (1x2)2 = 49
বা, x4 + 2 + 1x4 = 49
বা, x4 + 1x4 = 49 − 2
বা, x4 + 1x4 = 47 (প্রমাণিত)
(গ) এর সমাধান:
প্রদত্ত রাশি = P × Q ÷ a3 + b3a − b

মান বসিয়ে পাই,
= a3 − b3a + b × a2 − ab + b2a2 − b2 ÷ a3 + b3a − b

সূত্রের রূপান্তর করে পাই,
= (a − b)(a2 + ab + b2)a + b × a2 − ab + b2(a + b)(a − b) × a − b(a + b)(a2 − ab + b2)

লব ও হরের সাধারণ উৎপাদকগুলো কাটাকাটি করে পাই,
= (a − b)(a2 + ab + b2)(a + b)3
= a3 − b3(a + b)3
উত্তর: a3 − b3(a + b)3
উদ্দীপক: X = 1a2 − 5a + 6, Y = 1a2 − 7a + 12 এবং Z = 1a2 − 9a + 20 তিনটি বীজগণিতীয় ভগ্নাংশ।
  • (ক) x2 − 9x2 + 6x + 9 কে লঘিষ্ঠ আকারে প্রকাশ করো। [২]
  • (খ) X + Y এর মান নির্ণয় করো। [৪]
  • (গ) সরল করো: X + Y − Z [৪]

সমাধান ৩:

(ক) এর সমাধান:
প্রদত্ত ভগ্নাংশ = x2 − 9x2 + 6x + 9
লব = x2 − 32 = (x + 3)(x − 3)
হর = x2 + 2 × x × 3 + 32 = (x + 3)2 = (x + 3)(x + 3)

ভগ্নাংশটি = (x + 3)(x − 3)(x + 3)(x + 3) = x − 3x + 3
উত্তর: x − 3x + 3
(খ) এর সমাধান:
X এর হর = a2 − 5a + 6 = a2 − 3a − 2a + 6 = a(a − 3) − 2(a − 3) = (a − 3)(a − 2)
Y এর হর = a2 − 7a + 12 = a2 − 4a − 3a + 12 = a(a − 4) − 3(a − 4) = (a − 4)(a − 3)

অতএব, X + Y = 1(a − 3)(a − 2) + 1(a − 4)(a − 3)
হরগুলোর ল.সা.গু = (a − 2)(a − 3)(a − 4)

= (a − 4) + (a − 2)(a − 2)(a − 3)(a − 4)
= 2a − 6(a − 2)(a − 3)(a − 4)
= 2(a − 3)(a − 2)(a − 3)(a − 4)
= 2(a − 2)(a − 4)
উত্তর: 2(a − 2)(a − 4)
(গ) এর সমাধান:
Z এর হর = a2 − 9a + 20 = a2 − 5a − 4a + 20 = a(a − 5) − 4(a − 5) = (a − 4)(a − 5)

সুতরাং, Z = 1(a − 4)(a − 5)

'খ' হতে পাই, X + Y = 2(a − 2)(a − 4)

অতএব, X + Y − Z = 2(a − 2)(a − 4) − 1(a − 4)(a − 5)

হরগুলোর ল.সা.গু = (a − 2)(a − 4)(a − 5)

= 2(a − 5) − 1(a − 2)(a − 2)(a − 4)(a − 5)
= 2a − 10 − a + 2(a − 2)(a − 4)(a − 5)
= a − 8(a − 2)(a − 4)(a − 5)
উত্তর: a − 8(a − 2)(a − 4)(a − 5)
