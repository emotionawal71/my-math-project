    <div class="mcq-card">
        <div class="question">১. $x - \frac{1}{x} = 4$ হলে, $x^2 + \frac{1}{x^2}$ এর মান কত?</div>

            <div>(ক) 14</div>
            <div>(খ) 16</div>
            <div>(গ) 18</div>
            <div>(ঘ) 20</div>
        </div>
        <div class="answer-box">
            <div class="correct-ans">সঠিক উত্তর: (গ) 18</div>
            <div class="explanation">ব্যাখ্যা: $x^2 + \frac{1}{x^2} = (x - \frac{1}{x})^2 + 2 \cdot x \cdot \frac{1}{x} = 4^2 + 2 = 16 + 2 = 18$।</div>
        </div>

    <!-- Question 2 -->
    <div class="mcq-card">
        <div class="question">২. $a + b = 3$ এবং $ab = 2$ হলে, $a^3 + b^3$ এর মান কত?</div>
        <div class="options">
            <div>(ক) 9</div>
            <div>(খ) 18</div>
            <div>(গ) 27</div>
            <div>(ঘ) 35</div>
        </div>
        <div class="answer-box">
            <div class="correct-ans">সঠিক উত্তর: (ক) 9</div>
            <div class="explanation">ব্যাখ্যা: $a^3 + b^3 = (a + b)^3 - 3ab(a + b) = (3)^3 - 3(2)(3) = 27 - 18 = 9$।</div>
        </div>
    </div>

        <div class="question">৩. $x^2 - 5x + 6$ এর উৎপাদকে বিশ্লেষিত রূপ কোনটি?</div>
        <div class="options">
            <div>(ক) $(x - 1)(x - 6)$</div>
            <div>(খ) $(x - 2)(x - 3)$</div>
            <div>(গ) $(x + 2)(x + 3)$</div>
            <div>(ঘ) $(x + 1)(x - 6)$</div>
        </div>
        <div class="answer-box">
            <div class="correct-ans">সঠিক উত্তর: (খ) $(x - 2)(x - 3)$</div>
            <div class="explanation">ব্যাখ্যা: $x^2 - 3x - 2x + 6 = x(x - 3) - 2(x - 3) = (x - 2)(x - 3)$।</div>
        </div>
    </div>

            <div class="explanation">ব্যাখ্যা: অনুসিদ্ধান্ত অনুযায়ী, যদি $a + b + c = 0$ হয়, তবে $a^3 + b^3 + c^3 = 3abc$।</div>

            <div class="correct-ans">সঠিক উত্তর: (খ) 2</div>
            <div class="explanation">ব্যাখ্যা: $f(2) = 2^3 - 2 - 6 = 8 - 8 = 0$। অতএব, $x = 2$।</div>
        </div>
    </div>

        <div class="question">৬. $x + \frac{1}{x} = \sqrt{3}$ হলে, $x^3 + \frac{1}{x^3}$ এর মান কত?</div>
        <div class="options">
            <div>(ক) 0</div>
            <div>(খ) 1</div>
            <div>(গ) $3\sqrt{3}$</div>

            <div class="correct-ans">সঠিক উত্তর: (ক) 0</div>
            <div class="explanation">ব্যাখ্যা: $x^3 + \frac{1}{x^3} = (x + \frac{1}{x})^3 - 3(x + \frac{1}{x}) = (\sqrt{3})^3 - 3\sqrt{3} = 3\sqrt{3} - 3\sqrt{3} = 0$।</div>
        </div>
