উচ্চতর গণিত (নবম-দশম শ্রেণি): জ্যামিতি

প্রশ্ন: $\triangle ABC$ এর মধ্যমাত্রয় $G$ বিন্দুতে মিলিত হলে প্রমাণ কর যে, $AB^2 + BC^2 + CA^2 = 3(GA^2 + GB^2 + GC^2)$

জ্যামিতিক চিত্র

চিত্র: $\triangle ABC$ এর মধ্যমাত্রয় $AD, BE, CF$ এবং ভরকেন্দ্র $G$

বিশেষ নির্বচন:

মনে করি, $\triangle ABC$ এর মধ্যমাত্রয় $AD, BE, CF$ পরস্পরকে $G$ বিন্দুতে ছেদ করেছে। সুতরাং $G$ হলো ত্রিভুজটির ভরকেন্দ্র।

প্রমাণ করতে হবে যে, $AB^2 + BC^2 + CA^2 = 3(GA^2 + GB^2 + GC^2)$

প্রমাণ (ধাপ ১ - বাহু ও মধ্যমার সম্পর্ক):

অ্যাপোলোনিয়াসের উপপাদ্যের বিস্তৃত সিদ্ধান্ত অনুসারে ত্রিভুজের বাহু এবং মধ্যমাত্রয়ের মধ্যে সম্পর্কটি হলো—

$$3(AB^2 + BC^2 + CA^2) = 4(AD^2 + BE^2 + CF^2) \quad \dots\dots\text{ (i)}$$
প্রমাণ (ধাপ ২ - ভরকেন্দ্র দ্বারা মধ্যমার বিভাজন):

আমরা জানি, ত্রিভুজের ভরকেন্দ্র প্রতিটি মধ্যমাকে শীর্ষ থেকে $2:1$ অনুপাতে অন্তর্বিভক্ত করে।

$$\therefore \frac{GA}{GD} = \frac{2}{1}$$ $$\implies \frac{GD}{GA} = \frac{1}{2} \quad \text{[ব্যস্তকরণ করে]}$$ $$\implies \frac{GD + GA}{GA} = \frac{1 + 2}{2} \quad \text{[যোজন করে]}$$ $$\implies \frac{AD}{GA} = \frac{3}{2} \quad [\because GD + GA = AD]$$
প্রমাণ (ধাপ ৩ - মধ্যমা ও ভরকেন্দ্রীয় দূরত্বের বর্গ):

বজ্রগুণন এবং উভয়পাশে বর্গ করে পাই,

$$2AD = 3GA$$ $$\implies (2AD)^2 = (3GA)^2$$ $$\implies 4AD^2 = 9GA^2 \quad \dots\dots\text{ (ii)}$$

একইভাবে অপর মধ্যমাগুলোর ক্ষেত্রে পাওয়া যায়,

$$4BE^2 = 9GB^2 \quad \dots\dots\text{ (iii)}$$ $$4CF^2 = 9GC^2 \quad \dots\dots\text{ (iv)}$$
প্রমাণ (ধাপ ৪ - সমীকরণসমূহ যোগ করা):

সমীকরণ $\text{(ii)} + \text{(iii)} + \text{(iv)}$ যোগ করে পাই,

$$4AD^2 + 4BE^2 + 4CF^2 = 9GA^2 + 9GB^2 + 9GC^2$$ $$\implies 4(AD^2 + BE^2 + CF^2) = 9(GA^2 + GB^2 + GC^2) \quad \dots\dots\text{ (v)}$$
প্রমাণ (ধাপ ৫ - চূড়ান্ত প্রতিস্থাপন):

এখন, সমীকরণ $\text{(i)}$-এ সমীকরণ $\text{(v)}$-এর মান বসিয়ে পাই,

$$3(AB^2 + BC^2 + CA^2) = 9(GA^2 + GB^2 + GC^2)$$ $$\implies AB^2 + BC^2 + CA^2 = \frac{9}{3}(GA^2 + GB^2 + GC^2)$$ $$\mathbf{\therefore AB^2 + BC^2 + CA^2 = 3(GA^2 + GB^2 + GC^2) \quad \text{[প্রমাণিত]}}$$
