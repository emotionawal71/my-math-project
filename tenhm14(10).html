উচ্চতর গণিত — সৃজনশীল প্রশ্নের সমাধান

অধ্যায় ১৪: সম্ভাবনা (মুদ্রা নিক্ষেপ ও প্রোবাবিলিটি ট্রি)

উদ্দীপক:
একটি দুই টাকার মুদ্রা চার বার নিক্ষেপ করা হলো। (এর শাপলার পিঠকে L এবং প্রাথমিক শিক্ষার শিশুর পিঠকে C বিবেচনা করো)
প্রশ্নসমূহ:
ক) যদি মুদ্রাটিকে চারবারের পরিবর্তে দুইবার নিক্ষেপ করা হয় তবে একটি L আসার সম্ভাবনা এবং একটি C না আসার সম্ভাবনা কত?
খ) সম্ভাব্য ঘটনার Probability tree অঙ্কন করো এবং নমুনাক্ষেত্রটি লেখো।
গ) দেখাও যে, মুদ্রাটি n সংখ্যক বার নিক্ষেপ করলে সংঘটিত ঘটনা সংখ্যা 2^n হয়।
ধাপ ১ দুইবার নিক্ষেপের নমুনা ক্ষেত্র গঠন
মুদ্রাটি চারবারের পরিবর্তে দুইবার নিক্ষেপ করা হলে সম্ভাব্য ফলাফলগুলো হবে:
নমুনা ক্ষেত্র, S = {LL, LC, CL, CC}
মোট ফলাফল সংখ্যা, n(S) = ৪।
ধাপ ২ একটি L আসার সম্ভাবনা নির্ণয়
'একটি L' আসার অনুকূল ফলাফলগুলো হলো: {LC, CL}
অনুকূল ফলাফলের সংখ্যা = ২।

অতএব, P(একটি L আসার সম্ভাবনা) = অনুকূল ফলাফল / মোট ফলাফল = ২/৪ = ১/২।
ধাপ ৩ একটি C না আসার সম্ভাবনা নির্ণয়
'একটি C না আসা' ঘটনাটির অর্থ হলো এমন ফলাফল যেখানে C-এর সংখ্যা ১ নয় (অর্থাৎ C শূন্যটি অথবা C দুটি):
অনুকূল ফলাফলসমূহ: {LL, CC}
অনুকূল ফলাফলের সংখ্যা = ২।

অতএব, P(একটি C না আসার সম্ভাবনা) = ২/৪ = ১/২।

[বিশেষ দ্রষ্টব্য: যদি প্রশ্নটির অর্থ 'একটিও C না আসা' অর্থাৎ কোনো C থাকবে না বোঝানো হয়, তবে অনুকূল ঘটনা = {LL}, যার সম্ভাবনা = ১/৪।]
ধাপ ১ / ৩
ধাপ ১ চারবার নিক্ষেপের প্রোবাবিলিটি ট্রি (Probability Tree)

নিচে মুদ্রাটি ৪ বার নিক্ষেপের সম্পূর্ণ ১৬টি শাখার প্রোবাবিলিটি ট্রি দেখানো হলো:

ধাপ ২ সম্পূর্ণ নমুনা ক্ষেত্র (Sample Space) উপস্থাপন
ট্রি থেকে প্রাপ্ত চারবার মুদ্রা নিক্ষেপের নমুনা ক্ষেত্রটি হলো:

S = {
  LLLL, LLLC, LLCL, LLCC,
  LCLL, LCLC, LCCL, LCCC,
  CLLL, CLLC, CLCL, CLCC,
  CCLL, CCLC, CCCL, CCCC
}

এখানে, মোট নমুনা বিন্দুর সংখ্যা, n(S) = ১৬।
ধাপ ১ / ২
ধাপ ১ মুদ্রা নিক্ষেপের সংখ্যা ও ফলাফলের সম্পর্ক পর্যবেক্ষণ
একটি মুদ্রা প্রতিবার নিক্ষেপ করলে সম্ভাব্য ২টি ফলাফল (L অথবা C) পাওয়া যায়।

• মুদ্রাটি ১ বার নিক্ষেপ করলে সংঘটিত ঘটনা সংখ্যা = ২ = 2^1
• মুদ্রাটি ২ বার নিক্ষেপ করলে সংঘটিত ঘটনা সংখ্যা = ৪ = 2^2
• মুদ্রাটি ৩ বার নিক্ষেপ করলে সংঘটিত ঘটনা সংখ্যা = ৮ = 2^3
• মুদ্রাটি ৪ বার নিক্ষেপ করলে সংঘটিত ঘটনা সংখ্যা = ১৬ = 2^4
ধাপ ২ গাণিতিক আরোহ বা সার্বিক সাধারণীকরণ
দেখা যাচ্ছে যে, প্রতিটি অতিরিক্ত নিক্ষেপের জন্য সম্ভাব্য ঘটনা আগের ঘটনার দ্বিগুণ হয়।

সুতরাং, মুদ্রাটি n সংখ্যক বার নিক্ষেপ করলে সংঘটিত মোট ঘটনার সংখ্যা হবে:
= ২ × ২ × ২ × ...... × ২ (n সংখ্যক বার)
= 2^n

অতএব, মুদ্রাটি n সংখ্যক বার নিক্ষেপ করলে সংঘটিত ঘটনা সংখ্যা 2^n হয়।
(দেখানো হলো)
